# UK-Road-Accident-Analysis-Dashboard
Developed an interactive UK Road Accident Analysis Dashboard using Power BI to analyze accident trends, casualties, vehicle types, road conditions, and accident severity. The dashboard provides insights through interactive visualizations and filters to support data-driven road safety analysis.
# UK Road Accident Analysis Dashboard

## 📌 Project Overview
The UK Road Accident Analysis Dashboard is a Power BI project designed to analyze road accidents and casualty patterns across the United Kingdom. It helps explore accident severity, vehicle involvement, road conditions, and trends over time through interactive visualizations.

## 🎯 Objectives
- Analyze road accident and casualty trends.
- Compare accident severity levels.
- Examine accidents by vehicle type and road conditions.
- Identify patterns across different time periods.
- Present insights to support road safety analysis.

## 🛠️ Tools and Technologies
- **Power BI Desktop** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation, where applicable
- **DAX** – Measures and calculations, where applicable
- **Dataset** – UK road accident data

## 📊 Dashboard Features
- Accident and casualty analysis
- Accident severity breakdown
- Vehicle-type analysis
- Road condition and road-type analysis
- Time-based trend analysis
- Interactive charts, slicers, and filters

## 🚀 How to Use
1. Download or clone this repository.
2. Install Power BI Desktop.
3. Open `UK Road Accident Analysis.pbix`.
4. Explore the dashboard pages and interact with the available filters and visualizations.

## 💡 Key Learnings
- Data cleaning and transformation
- Interactive dashboard development
- Data visualization and analytical storytelling
- Identifying trends and patterns in road accident data
